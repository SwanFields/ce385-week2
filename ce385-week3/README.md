เนื้อหาในนี้คือการสรุปการเขียนฟังก์ชันทั้ง 3 ส่วน` 

ในส่วนแรกเป็นการจำลองระบบคำนวณคะแนนและตัดเกรดของนักศึกษา
- การคำนวณและตัดเกรด มีการสร้างฟังก์ชันตรวจสอบความถูกต้องของคะแนน และใช้เมธอด .find() เพื่อเทียบช่วงคะแนนและตัดเกรดจากเงื่อนไข GRADE_CRITERIA 
- ฟังก์ชัน calculateWorkshopScore มีการกำหนดค่าเริ่มต้นให้กับพารามิเตอร์ (เช่น `full = 60`, `weight = 20`) ทำให้ถ้าไม่ส่งค่าเข้าไป ฟังก์ชันก็ยังทำงานได้ หรือถ้าส่ง undefined เข้าไปตรงกลาง ฟังก์ชันก็จะดึงค่า Default มาใช้
- การสร้างตารางสรุปผลใช้ .map() เพื่อลูปข้อมูลนักศึกษาจำลอง นำมาคำนวณคะแนนรวมและเกรด แล้วจัดให้อยู่ในรูปแบบ Object เพื่อง่ายต่อการนำไปแสดงผลผ่าน console.table()

ส่วนที่สองคือการค้นหาข้อมูลนักศึกษาจาก Array of Objects
- ใช้ .find() เพื่อหาตัวนักศึกษาจาก ID
- ใช้ .filter() เพื่อหากลุ่มนักศึกษาตามสาขาวิชา
- ใช้ .some() เพื่อเช็คว่ามีนักศึกษาคนไหนได้คะแนนน้อยกว่า 50 หรือไม่
- ในฟังก์ชัน getEmail มีการใช้ student?.contact?.email เพื่อป้องกันโปรแกรมพังกรณีที่ข้อมูลนักศึกษาบางคนไม่มี Object `contact` และใช้ `?? "ไม่พบข้อมูลติดต่อ"` เพื่อถ้าหากข้อมูลนั้นเป็น null หรือ undefined ก็จะแสดงข้อความีท่กำหนดไป
- มีการใช้ [...students, newStudent] เพื่อเพิ่มข้อมูลนักศึกษาคนใหม่เข้าไปใน Array โดยไม่กระทบกับข้อมูลชุดเดิม

ส่วนสุดท้ายเป็นการสรุปผลข้อมูล
- ใช้ .map() เพื่อดึงมาเฉพาะรายชื่อนักศึกษา และ .filter() เพื่อกรองเฉพาะคนที่สอบผ่านเกณฑ์
- ใช้ (`.reduce()`) เพื่อรวมค่า
  - ใช้รวบรวมคะแนนของทุกคน และนำมาหารเพื่อหาค่าเฉลี่ย
  - การจัดกลุ่มข้อมูล (Tallying):** ใช้เพื่อนับจำนวนนักศึกษาในแต่ละช่วงเกรด (`countByGrade`) โดยเก็บผลลัพธ์ลงใน Object (เช่น มีคนได้เกรด A หรือ B กี่คน)
  - ใช้เปรียบเทียบคะแนนเพื่อหานักศึกษาที่ได้คะแนนสูงสุด (`getTopStudent`)
- มีการนำเมธอดมาต่อกัน เช่น .filter().map().reduce() เพื่อหาค่าเฉลี่ยของเด็กสาขา CE ที่สอบผ่าน ทำให้โค้ดกระชับขึ้น
- โค้ดมีการดักจับกรณีที่ส่ง Array ว่างเปล่า (`emptyStudents`) เข้าไป เพื่อไม่ให้คำนวณผิดพลาด (เช่น ป้องกันการหารด้วยศูนย์)
